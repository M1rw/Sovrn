# Project Overview

Last updated: 2026-04-18

## Mission

SOVRN is a production AI website platform with self-managed inference, strong orchestration controls, and operational traceability.

## Product Scope

1. Generate production-ready web projects from structured user intent.
2. Provide stable multi-agent orchestration with quality controls.
3. Support secure deployment paths including Supabase-backed infrastructure.
4. Keep release decisions measurable through gates, logs, and audits.

## Success Criteria

- Stable generation quality across fast, balanced, and high quality modes.
- Staging latency and canary gates pass before production promotion.
- Every major change has matching plan, tracking, and validation evidence.
