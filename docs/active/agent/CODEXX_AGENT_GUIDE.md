# Codex Agent Guide

Last updated: 2026-04-18

## Purpose

Provide a single, repeatable workflow for implementation sessions so project status, risk, and evidence stay current.

## Required Session Flow

1. Read tracking/PROJECT_DASHBOARD.md and planning/MASTER_EXECUTION_PLAN.md.
2. Implement scoped changes.
3. Run relevant tests and validation commands.
4. Update tracking/DELIVERY_LOG.md with outcomes.
5. Update planning/backlog docs if priorities changed.
6. Update tracking/RISKS_AND_BLOCKERS.md when risk profile changes.

## Mandatory Documentation Updates

- Any behavior change: update operations docs when contract/runbook impact exists.
- Any priority change: update planning/ENGINEERING_BACKLOG.md.
- Any gate execution: update tracking/PROJECT_DASHBOARD.md and DELIVERY_LOG.md.

## Done Criteria

A task is not complete until code changes, verification, and tracking doc updates are all finished.
